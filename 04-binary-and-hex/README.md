# Binary and Hexadecimal Fundamentals

## What I learned

Computers represent information using bits (0 and 1). The same bit pattern can have different interpretations depending on whether it is treated as unsigned or signed two's-complement data.

## Example: 8-bit representation

Binary: `11111110`

- Unsigned decimal: 254
- Signed decimal: -2
- Hexadecimal: `FE`

## Key concepts

- One hexadecimal digit represents four bits.
- One byte contains eight bits.
- An 8-bit unsigned integer ranges from 0 to 255.
- An 8-bit two's-complement integer ranges from -128 to 127.
